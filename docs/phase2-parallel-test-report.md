# Phase 2.2: 批量并行因子测试报告

**测试日期**: 2026-04-29  
**测试方法**: Hermes delegate_task 并行执行  
**测试期间**: 2024-01-01 至 2026-03-11 (约 27 个月)  
**选股数量**: 20 只  

---

## 执行概况

### 并行任务执行
- **任务数量**: 4 个因子
- **并发限制**: 3 个（系统配置）
- **执行方式**: 分两批执行
  - 第一批: momentum_20, earnings_yield, book_yield
  - 第二批: turnover_shock_5_20
- **总耗时**: ~10 分钟

### 测试因子
1. **momentum_20** - 动量因子（20日动量）
2. **earnings_yield** - 价值因子（盈利收益率）
3. **book_yield** - 价值因子（账面收益率）
4. **turnover_shock_5_20** - 波动因子（换手率冲击）

## 详细分析

### 1. earnings_yield (盈利收益率)
**表现**: 最差  
**关键指标**:
- Rank IC: 0.0041 (极弱预测能力)
- Sharpe (净): -6.26 (风险调整后收益极差)
- 年化收益: -321.5% (灾难性亏损)
- 观测数: 26,922 (数据最充分)

**失败原因**:
- `rank_ic_mean < 0.02` (低于最低阈值)
- `top_bottom_spread < 0.0005` (多空价差为负)
- `sharpe_net < 1.0` (风险调整后收益不达标)

**诊断**:
- 虽然观测数最多，但预测能力几乎为零
- 多空价差为负值 (-0.0059)，说明因子方向可能反向
- 毛 Sharpe 已经是负值 (-2.90)，交易成本进一步恶化

### 2. book_yield (账面收益率)
**表现**: 差  
**关键指标**:
- Rank IC: -0.0097 (负值，预测方向错误)
- Sharpe (净): -3.85
- 年化收益: -375.6%
- 观测数: 4,915

**失败原因**:
- `rank_ic_mean < 0.01`
- `top_bottom_spread < 0.0001` (多空价差为负)
- `sharpe_net < 1.0`

**诊断**:
- Rank IC 为负，说明因子与未来收益负相关
- 观测数较少，可能是数据缺失导致
- 多空价差 -0.0081，方向完全反向

### 3. turnover_shock_5_20 (换手率冲击)
**表现**: 相对最好（但仍然失败）  
**关键指标**:
- Rank IC: 0.0002 (接近零)
- Sharpe (净): -0.49 (相对最好)
- 年化收益: -241.8%
- 观测数: 4,300

**失败原因**:
- `rank_ic_mean < 0.03`
- `top_bottom_spread < 0.0` (多空价差为负)
- `sharpe_net < 1.0`

**诊断**:
- 毛 Sharpe -0.14，相对其他因子好很多
- 但扣除交易成本后仍为负值
- 预测能力几乎为零 (IC = 0.0002)

---

## 共同问题分析

### 1. 所有因子均未通过质量门槛
- **Rank IC 过低**: 全部 < 0.01，远低于 0.03 的最低要求
- **Sharpe 比率为负**: 风险调整后收益全部为负
- **多空价差为负**: 说明因子方向可能需要反转

### 2. 交易成本侵蚀严重
- 所有因子换手率均为 20%
- 交易成本统一为 68.53 bps
- 在毛收益已经为负的情况下，交易成本进一步恶化

### 3. 观测数差异巨大
- earnings_yield: 26,922 (最多)
- book_yield: 4,915
- turnover_shock_5_20: 4,300

**可能原因**: 不同因子的数据可得性不同，某些字段可能存在大量缺失值。

---

## 根本原因推测

### 1. 测试期间问题
- **时间范围**: 2024-01-01 至 2026-03-11
- **可能问题**: 这是未来时间（相对于数据采集时间），可能存在数据质量问题
- **建议**: 使用历史数据（如 2020-2023）重新测试

### 2. 因子表达式过于简单
- 所有因子都是单一字段，未经任何变换
- 缺少行业中性化、市值中性化
- 缺少因子组合和优化

### 3. 选股数量过少
- 仅 20 只股票，分散化不足
- 容易受到个股特异风险影响
- 建议增加到 50-100 只

### 4. 数据质量问题
- 观测数差异巨大，说明数据缺失严重
- 可能存在前视偏差（look-ahead bias）
- 需要检查数据对齐和时间戳

2. **增加选股数量**
   - 从 20 只增加到 50-100 只
   - 提高分散化程度

3. **测试因子反转**
   - 尝试 `-earnings_yield`, `-book_yield`

### 中期优化（需要开发）
1. **因子中性化**
   - 行业中性化

2. **因子组合**
   - 测试多因子组合: `earnings_yield + book_yield`

3. **参数优化**
   - 测试不同窗口的动量因子
   - 优化换手率控制参数
