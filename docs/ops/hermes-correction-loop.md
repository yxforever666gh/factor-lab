# Hermes Correction Loop

This document defines the temporary Hermes subagent correction loop for Factor Lab operational blockers. These are **Hermes temporary subagent prompts**, not Factor Lab provider/model profiles, not local persistent `hermes` CLI agents, and not model/provider pinning inside Factor Lab.

## Purpose

The correction loop turns a blocker artifact into a bounded, artifact-backed handoff:

```text
failure artifact / blocker
  -> factor-lab-diagnostician
  -> correction state/proposal artifact
  -> factor-lab-implementer or bounded executor
  -> factor-lab-verifier
  -> factor-lab-reviewer
  -> factor-lab-knowledge-steward
  -> next action / stop / data request
```

## State artifacts

The current deterministic handoff lives at:

- `artifacts/hermes_correction/current_state.json`
- `artifacts/hermes_correction/current_state.md`

The state is generated by `scripts/write_hermes_correction_state.py` and inspected by `scripts/inspect_hermes_correction_status.py`.

## Conservative defaults

Correction state must keep these defaults unless a human explicitly creates a separate approved operational process:

- `manual_review_required=true`
- `queue_write_allowed=false`
- `automation_allowed=false`
- `live_trading_enabled=false`

## Guardrails

Temporary Hermes subagents must not:

- write workflow queues,
- enable timers,
- change systemd units,
- restore broad daemons,
- auto-promote candidates,
- relax drawdown gates to force a pass,
- create persistent local Hermes CLI agents,
- pin or modify Factor Lab model/provider profiles.

## Temporary Hermes subagent roles

- `factor-lab-diagnostician`: reads blocker artifacts, classifies root cause, proposes next action.
- `factor-lab-implementer`: edits bounded code/artifacts with tests and no runtime side effects.
- `factor-lab-verifier`: runs targeted verification and checks artifact consistency.
- `factor-lab-reviewer`: reviews safety, scope, and manual-review requirements.
- `factor-lab-knowledge-steward`: updates project docs/knowledge after verified changes.

Again: these are temporary Hermes subagent roles/prompts only. They are not Factor Lab provider/model profiles and do not configure LLM providers.
